# KnowledgeFlow RAG Studio

A polished portfolio demo showing a practical retrieval-augmented generation workspace for business documents.

## What it demonstrates

- React interface for document Q&A
- Simulated RAG answer generation with citations
- Source filtering and retrieval confidence views
- Business-focused UX for policy, finance, legal, and operations documents

## Tech stack

React, Vite, JavaScript, CSS, lucide-react

## Run locally

```bash
npm install
npm run dev
```

## Portfolio note

This demo is intentionally self-contained so reviewers can understand the product flow without API keys. In a production build, the retrieval layer would connect to OpenAI embeddings, a vector database, document parsing, and backend authentication.
